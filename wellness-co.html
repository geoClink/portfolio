The Problem

Solo wellness practitioners — acupuncturists, energy healers, Reiki providers — are paying $100–200/month for platforms like Mindbody or Vagaro that were built for large gyms and feel like it. The booking UX is generic, the branding belongs to the platform, and the features they're paying for go mostly unused. The goal was a fully custom-branded booking experience the practitioner owns outright, with no ongoing software cost.

The Approach

The booking confirmation flow is webhook-driven rather than tied to the booking endpoint — Stripe fires a webhook after payment clears, which writes the appointment to Supabase and sends the confirmation email via Resend. This means a failed or abandoned payment never results in a confirmed appointment in the database.

Each appointment is issued a UUID cancel token at insert time. The confirmation email carries that token in a link — no login required, and the URL can't be guessed or enumerated. When a client clicks the link, the server calculates time remaining and determines their refund tier: full refund beyond 48 hours, 50% inside, nothing for no-shows. Rescheduling always issues a full refund regardless of timing. All refunds are executed server-side through the Stripe API automatically.

The admin dashboard is protected by Supabase Auth with a rate-limited login endpoint and JWT validation on every protected route. Practitioners can manage services, appointments, availability, blocked dates, and reviews — and connect their own Stripe and Resend accounts — without touching code. Password reset is handled through a tokenized email flow that lands back on the dashboard.

The architecture is multi-tenant from day one. A single middleware reads a TENANT_SLUG environment variable and scopes every database query to that tenant's data. Onboarding a new practitioner means inserting a row and deploying a new Vercel project — no schema changes, no code forks.

The Outcome

Built for a real client and currently in final handoff — a solo wellness practitioner replacing a $100–200/month Mindbody subscription with a platform they own outright. The multi-tenant architecture means white-labeling for additional practitioners requires no code changes: insert a row, deploy a Vercel project, done. The goal is to grow this into a full white-label suite under CH Studios. 100/100/100 Lighthouse scores across Performance, Accessibility, and SEO.
