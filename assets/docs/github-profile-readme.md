## Small Business Suite

One backend. Six live sites. A multi-tenant SaaS platform serving real clients across wellness, bakery, salon, sports bar, and hospitality — booking, payments, staff scheduling, loyalty, and admin dashboards in one codebase. Per-tenant Stripe keys live in the database so adding a client never requires a backend redeploy. 130 passing tests · Sentry in production.
