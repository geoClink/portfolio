# Portfolio — George Clinkscales Jr.

Live site: https://geoclink.github.io/portfolio/

Personal portfolio for George Clinkscales Jr., iOS & full-stack engineer and co-founder of CH Studios LLC, based in Detroit, MI.

Built from scratch on top of the HTML5 UP Future Imperfect template (heavily customized — custom design system, mobile nav, animations, and all content).

## Tech Stack

- HTML5, CSS3, vanilla JavaScript — no frameworks or build tools
- CSS custom properties for the full design system (colors, fonts, spacing)
- Mobile-first responsive design
- Font Awesome for icons
- Formspree for contact form handling
- Hosted on GitHub Pages

---

## Key Features

- Custom mobile nav with slide-in sidebar and dark overlay
- Resume accordion (mobile: tap to expand, desktop: always visible)
- Scroll reveal animations
- CSS-only iPhone and iPad mockups for case study screenshots
- Apple Developer Academy badge grid
- Open Graph / Twitter card meta on every page
- 100/100/100 Lighthouse scores across Performance, Accessibility, and SEO
