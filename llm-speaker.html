Local LLM Speaker

A fully private, offline smart speaker built from scratch — no cloud, no subscription, no voice data leaving the home network.

Python · Faster-Whisper · Ollama · Qwen3 4B · Piper TTS · Node.js · Express · WebSockets · Raspberry Pi 5 · ESP32-S3 · 2026 · Personal Project

The Problem

Every mainstream smart speaker — Alexa, Google Home, Siri — sends your voice to a remote server to process it. Your home conversations, your daily schedule, your shopping list: all of it leaves the house. The only way to get a capable AI assistant without that tradeoff is to build one that never makes the call.

The Hardware

The speaker runs on a Raspberry Pi 5 (8GB) with an NVMe SSD for fast model loading and persistent storage. Audio capture and wake word detection are handled by a custom ESP32-S3 PCB — a microcontroller board I designed specifically for this build, responsible for listening at the edge and only waking the Pi when a trigger is detected. The result is a device that idles at near-zero power and wakes in under a second.

The Pipeline

Every request runs through a four-stage local pipeline — nothing touches the internet except for data fetches like weather or sports scores.

01 faster-Whisper Voice → text, on-device
02 Ollama / Qwen3 4B LLM inference, fully local
03 Tool Execution Weather, music, calendar…
04 Piper TTS Text → speech, on-device

A Python pipeline (pipeline.py) orchestrates the full loop. Voice is captured and transcribed locally by faster-Whisper. The transcript is handed to Qwen3 4B running via Ollama — fully on-device — which selects the right tool and generates a response. Piper TTS converts the response to speech and plays it back. A Node.js and Express backend with WebSockets keeps the web dashboard updated in real time throughout.

Tools

The LLM picks from a set of registered tools based on the request. All tool logic runs locally or fetches from external APIs — no personal data is ever sent.

  • Weather conditions and forecast
  • Sports scores and standings
  • YouTube music streaming
  • BBQ probe temps via Meater
  • Timers and alarms
  • Reminders
  • Google Calendar integration
  • Shopping list
  • News headlines
  • Jokes

The Dashboard

A vanilla JS web dashboard served at http://speaker.local:3000 gives full control over the device from any browser on the home network. Features include a voice selector, wake word settings, LLM model switcher, per-tool toggles, full conversation history, live system stats (CPU, RAM, uptime), music controls, shopping list management, and active timers. WebSockets push real-time updates from the pipeline to the dashboard without polling.

The Outcome

A capable AI assistant that handles weather, music, sports, cooking, and calendar — entirely on a $90 single-board computer, with zero monthly cost and zero data leaving the house. The only outbound calls are weather and sports data fetches and Meater cook temperatures. Everything else — transcription, inference, speech synthesis — runs on-device. The custom PCB means the device listens at the edge and only draws full power when it needs to respond.
