Detroit Sports Chatbot

A conversational AI chatbot that answers live questions about the Lions, Tigers, Red Wings, and Pistons — powered by real ESPN data and your choice of Claude or Groq.

View Live Demo GitHub ↗
Python · Streamlit · Claude API · Groq · ESPN API · 2026 · Live on Render

The Problem

Detroit sports fans needed a chatbot that knows what actually happened last night — not a generic AI wrapper. The goal was to learn AI tool use, prompt engineering with measurable evaluation, and secure Python deployment all at once.

The Approach

I defined 15 ESPN API tool schemas compatible with both Anthropic and Groq's formats. When a user asks a question, the model decides which tool to call and with what arguments — automatically. A tool use loop handles multi-step responses where the model needs to call more than one ESPN endpoint before it can answer.

Rather than guessing whether each system prompt iteration was better, I built an automated eval pipeline (eval.py) that uses an LLM to grade every response on a 1–5 scale. Running the chatbot against a fixed set of test questions after each prompt change gave measurable signal instead of gut feel — response quality went from 3.2 to 4.1 out of 5 across four iterations, a 28% improvement.

The app supports both Claude (Anthropic) and Groq (Llama 3.3 70b) via a sidebar switcher. All API keys are stored server-side and never passed to the browser. ESPN responses are cached for 30 seconds to balance freshness with rate limits. Deployed on Render free tier.

The Outcome

A live sports chatbot with AI tool use, word-by-word streaming, and a 28% measurable prompt quality improvement. The dual-provider setup demonstrates working knowledge of both the Anthropic and OpenAI-compatible API formats.
