The Bakery Co.

A full-stack ordering platform for a real bakery client — customer website, admin dashboard, and Supabase backend, all connected to a CH Studios iOS POS and customer app. The owner updates their menu once; the website and both iOS apps reflect it instantly.

Visit Live Site ↗
Node.js · Express · Supabase · Stripe · MCP Server · WebMCP · Resend · Twilio · CH Studios LLC · Live on Render

The Problem

Small bakeries take orders by phone or Instagram DM, lose track of them, and pay 15–30% commission to DoorDash or Uber Eats to get discovered online. There's no system, no paper trail, and no way to know which items are low on stock before the morning rush. Platforms like Square Online and Toast charge $200–500/month for what should be table stakes.

The Approach

Built as a five-surface business platform — customer website, admin CMS, iOS POS, iOS customer app, and an AI ordering layer — all sharing one Supabase database. A change made in the admin dashboard propagates to every connected surface in real time. No code. No redeploy. No developer on call.

The payment flow is webhook-first: the Stripe charge is confirmed before the order is written to the database, so no unpaid order ever enters the admin queue. Every admin API route verifies a JWT server-side — hiding a button in the browser isn't security. The entire stack is hand-written HTML, CSS, and JavaScript on the frontend, Node.js and Express on the backend, so the platform can be handed off as static files and a single server process.

The AI layer ships two integrations: a custom MCP server that lets customers browse the menu and place orders through Claude, and a WebMCP integration that registers menu search and checkout as browser-native AI tools — shipped the same week Google announced the W3C WebMCP standard at I/O 2026.

The Outcome

Zero commission per order versus 15–30% on delivery platforms. 100/100/100 Lighthouse scores across Accessibility, SEO, and Best Practices. The admin dashboard covers 16 sections — menu CMS, inventory, orders, revenue analytics, gift cards, subscriptions, loyalty rewards, coupons, prep list, and staff management — all reflected live across the website and iOS apps. The architecture is multi-tenant from day one: every table carries a tenant_id, so onboarding the next bakery client is one database row and a frontend deploy.
