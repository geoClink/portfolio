One API Server. Every Vertical.

As the platform grew from one client to five, maintaining separate backends became unsustainable. The solution was webplatform-api — a single Express/Supabase server that powers every frontend above. Each client is a tenant row in the database. Every fetch request includes an X-Tenant-Slug header; the server resolves the tenant, scopes all queries by tenant_id, and routes to the right vertical logic.

Per-tenant Stripe and Resend keys live in the database — not in environment variables — so adding a new client means inserting a row, not redeploying a server. A step-by-step onboarding wizard walks non-technical owners through connecting Stripe, Resend, and a custom domain via the Cloudflare API, which adds DNS records automatically. The same wizard ships to every vertical with vertical-specific steps swapped in.
