Live Web Platforms

A suite of production-ready websites built for small businesses that can't afford Toast or Squarespace — or shouldn't have to.

The idea: Small businesses — bakeries, salons, sports bars — are paying $30–150/month for platforms that weren't built for them. These three sites are purpose-built alternatives: fast, branded, fully functional, and owned outright. Each one is backed by an admin dashboard where the owner controls everything — menu items (add, edit, delete), business hours, inventory, event inquiries, contact form submissions, job applications, and financial insights like best sellers. Every change reflects live on the website and connected iOS apps. No code. No developer. No monthly platform fee.

What Each Site Has

  • Custom design built to each business's brand — no templates
  • Working forms via Formspree (contact, wholesale, reservations)
  • Client-side fuzzy search with Fuse.js across full product/menu catalogs
  • Scroll-driven animations with IntersectionObserver
  • Mobile-first, fully responsive — no framework
  • Deployed to a live domain, no CMS overhead

Why No Framework

All three sites are hand-written HTML, CSS, and JavaScript — no React, no Next.js, no CMS. The decision is deliberate: a small business owner shouldn't need a developer on retainer to update their hours. The sites load fast, cost nothing to host beyond a domain, and can be handed off as static files. The technical complexity (fuzzy search, Stripe integration, MCP server) lives in the JavaScript — not in a framework dependency tree that goes stale in six months.
