The Sports Bar Co.

A full-stack reservations and events platform for sports bars — table booking, a live events calendar, and a party inquiry form. Built as a direct alternative to Toast for owners who want a custom web presence without the platform lock-in.

Visit Live Site ↗
HTML · CSS · JavaScript · Node.js · Express · Supabase · Resend · Vercel

The Problem

Sports bars run on events — game days, watch parties, private buyouts — but most manage reservations by phone and promote events through Instagram stories that disappear after 24 hours. Toast and OpenTable charge hundreds per month and aren't built for the event-driven nature of sports bars. The goal was a platform that makes reservations and events first-class features: a site the owner controls completely, with no monthly platform fee and no commission per booking.

Technical Implementation

Reservation Flow

Table reservations use a date/time/party-size form that validates availability before writing the booking to Supabase. On confirmation, Resend fires a transactional email to the guest with their booking details. The owner sees all incoming reservations in the database without needing to check a third-party platform or pay a per-cover fee. Reservation data stays in a Supabase table the owner controls outright.

Events Calendar

The events page pulls live from the database — the owner adds or cancels events without touching any code. Each event entry includes a title, date, time, description, and optional image. The calendar displays upcoming events in chronological order and automatically drops past events from the public view, keeping the page accurate with zero maintenance.

Party & Buyout Inquiries

Private party and buyout leads come through a dedicated inquiry form separate from the table reservation flow. Submissions are written to Supabase and simultaneously routed to the owner's inbox via Resend, so no lead sits unread in a platform dashboard the owner has to remember to check.

Menu & Games

The menu page uses client-side filtering to let guests browse by category without a page reload — all menu data is in the DOM at load time, so filtering is instant and requires no API call. The games page surfaces live TV schedules so guests can see what's on before they arrive. Both pages are fully responsive and optimized for mobile, where most sports bar guests will be browsing.

Frontend Architecture

The frontend is built in vanilla HTML, CSS, and JavaScript — no framework. For a marketing site of this scope, a framework would add build tooling, bundle overhead, and maintenance surface without meaningful benefit. CSS custom properties handle theming; the mobile nav uses a fixed overlay with a backdrop-filter workaround to ensure it covers the full viewport across Chrome and Safari. The result is a fast, dependency-free site that any developer can maintain without knowing a specific framework.

The Outcome

A sports bar web presence that handles reservations, promotes events, and captures private party leads — all in one place, at a fraction of what off-the-shelf reservation platforms charge. The owner controls everything: add an event, update the menu, check incoming bookings — no developer required and no monthly platform fee. Part of the CH Studios Small Business Platform Suite.
